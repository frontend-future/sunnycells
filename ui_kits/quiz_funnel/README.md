# UI kit: Quiz funnel blocks

Nine screen types an onboarding quiz is assembled from, at 390px. Open `index.html`.

| # | Type | The rule |
|---|---|---|
| 01 | Start | States the promise and the time cost. Rating sits under the button. |
| 02 | Single select | Four options maximum, 64px rows. |
| 03 | Multi select | Square check, and always an honest opt-out row. |
| 04 | Social proof | A number she is inside of, then a reframe. |
| 05 | Reinforcement | Answers her previous answer, names the mechanism, then one real review. |
| 06 | Analyzing | Honest progress. No back button. Carries one study fact. |
| 07 | Result | Projection plus the study footnote on the same screen. |
| 08 | Commitment | Full-bleed sunny block, smallest real ask. |
| 09 | Offer | Integer price, dollar savings, routine itemised. |

## Funnel copy rules (on top of the brand voice)
- **Questions are sentence case in the display face**, not all caps. A shouted question reads as pressure. Statements and proof screens keep ALL CAPS.
- **No dark patterns.** No countdown timers, no fake scarcity, no "only 3 left", no shamed opt-out ("No thanks, I like my wrinkles"). The exit is always neutral.
- **No fake progress.** The analyzing screen shows real steps; do not pad it to feel like work.
- Every projection or statistic carries its study footnote on the same screen.
- Prices stay integers; savings stay in dollars.

## Placeholders
The start screen's yellow block is a labelled portrait placeholder. Product names, counts and the projection curve are invented to brand voice.
